Getting Started

Andy’s R5 Profiles is a working example of a personal Canon EOS R5 profile guide. Explore it first, then ask the application owner for access if you want to create your own.

Explore the example

The profile you were sent is the finished experience: camera profiles, field guidance, and an installable offline reference. Exploring it does not provide editing access or change anything.

Set up your own

  1. Create or sign in to your personal GitHub account.
  2. Reply to the person who sent this page with your exact GitHub username.
  3. The application owner sends Read access to the private Capture A GLOW application repository.
  4. Accept GitHub's invitation. Read access lets you download and update the application; it does not let you change the shared application repository.
  5. Open the detailed First-time Setup guide, prepare your Mac, and create a separate profile pack that you own.
